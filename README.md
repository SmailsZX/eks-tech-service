# ЭксТехСервис — Тестовое задание: 3 концепции лендинга

Ремонт спецтехники в Сыктывкаре. Три разные концепции одностраничного сайта.

## Структура проекта

```
eks-tech-service/
├── index.html              # Навигация между концепциями
├── README.md               # Этот файл
├── concept-01/             # ПРОМТЕХ — промышленный, тёмный, техно
│   ├── index.html
│   ├── style.css
│   └── script.js
├── concept-02/             # СЕРВИСПРО — дружелюбный, светлый, сервисный
│   ├── index.html
│   ├── style.css
│   └── script.js
└── concept-03/             # ЭКСЕКТ — минималистичный, премиум
    ├── index.html
    ├── style.css
    └── script.js
```

## Как открыть

1. Откройте `index.html` в браузере (двойной клик или перетащите в окно браузера)
2. Выберите концепцию кликом по карточке
3. Каждая концепция — самостоятельный одностраничный сайт

Альтернативно: откройте напрямую:
- `concept-01/index.html` — ПРОМТЕХ
- `concept-02/index.html` — СЕРВИСПРО
- `concept-03/index.html` — ЭКСЕКТ

## Концепции

### 01 — ПРОМТЕХ
- **Стиль**: промышленный, тёмный, техно
- **Палитра**: тёмный фон `#0F1217` + оранжевый акцент `#E8720C`
- **Шрифты**: Oswald (заголовки, uppercase) + Inter (тело)
- **Первый экран**: тёмный фон с сеткой, крупный uppercase-заголовок слева
- **Подача услуг**: карточки с иконками и оранжевой полоской
- **Впечатление**: мощь, надёжность, индустрия

### 02 — СЕРВИСПРО
- **Стиль**: дружелюбный, светлый, сервисный
- **Палитра**: белый фон + синий акцент `#1D6DC4` + зелёный `#2E9A6B`
- **Шрифты**: Manrope (заголовки) + Inter (тело)
- **Первый экран**: светлый, центрированный, иллюстрация-заглушка справа
- **Подача услуг**: карточки 3×2 с нумерацией и кнопкой «Заказать»
- **Впечатление**: доступность, доверие, «свои ребята»

### 03 — ЭКСЕКТ
- **Стиль**: минималистичный, премиум, editorial
- **Палитра**: тёплый белый `#FAFAF8` + монохром
- **Шрифты**: Playfair Display (крупные заголовки) + DM Sans (тело)
- **Первый экран**: много воздуха, serif-заголовок, контакты сбоку
- **Подача услуг**: нумерованный список без карточек
- **Впечатление**: экспертность, премиум, серьёзность

## Требования ТЗ — что реализовано

| Требование | Статус |
|---|---|
| 3 разные концепции (разные первые экраны, сетки, подача) | ✅ |
| Адаптивность: 390px + 1440px | ✅ |
| Без горизонтальной прокрутки | ✅ |
| HTML + CSS + JS (Tailwind не использован, чистый CSS) | ✅ |
| Кликабельные элементы | ✅ |
| Без Lorem ipsum | ✅ |
| Форма заявки с валидацией (демо) | ✅ |
| Заглушки вместо выдуманных данных | ✅ |
| Плавная прокрутка к секциям | ✅ |
| Мобильное меню (бургер) | ✅ |

## Используемые технологии

- Чистый HTML5, CSS3, Vanilla JS (без фреймворков)
- Google Fonts: Oswald, Manrope, Inter, Playfair Display, DM Sans
- CSS Grid + Flexbox для раскладки
- CSS custom properties (переменные) для палитры
- Медиа-запросы для адаптивности
- SVG-паттерны и градиенты вместо изображений

## Примечания

- Concept-03 использует Playfair Display только для крупных заголовков (16px+), 
  тело — DM Sans для читаемости.
- Все три концепции имеют идентичную структуру контента, но разную визуальную подачу.
- Формы работают в демо-режиме: при отправке показывается сообщение об успехе, 
  данные никуда не отправляются.
